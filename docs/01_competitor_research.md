## 2. 調べてわかったこと

1. **日本語ネイティブで「職場ストーリー型」のGit体験は見つからなかった。** 日本語の選択肢は、翻訳されたLGB、スライド形式のProgate、iOSアプリのGitQuestくらい。
2. **「他人が勝手にリポジトリを変える」を動的に起こすものはほぼない。** LGBの `fakeTeamwork` が近いが、演出も文脈もない。
3. **失敗をわざと体験させて、その結果を見せる設計はない。** 一番近いのはGit Visualizerの「Safe Undo Lab」（戻し方を比較する機能）。force push、`reset --hard`、秘密情報のcommit、main直pushなどを「やってみたら怒られる」形にしたものはない。
4. **操作の効率を測るものはあるが、数字を出すだけ。** LGBのGolfはコマンド数を表示するにとどまる。それを「後輩のまなざしが曇っていく」ような感情の演出に変えるのは新しい。
5. **ファイルの中身まで扱うシミュレーションは少ない。** LGBはコミットのノードだけ。コンフリクトの中身を直す、`.env` を誤ってcommitする、といった現場らしい体験にはファイル内容が必要。

## 3. 差別化ポイント（案）

| 軸         | 既存                       | git_sensei                                                 |
| ---------- | -------------------------- | ---------------------------------------------------------- |
| 言語・文化 | 翻訳                       | 日本の職場ネタ（頑固上司、後輩、朝会、金曜夕方のデプロイ） |
| 他者の存在 | ほぼない                   | NPCがシナリオに沿ってpushやforce pushをしてくる            |
| 失敗       | 避けさせる                 | **わざと失敗させる。** 上司の激怒演出と、その後の復旧手順  |
| 評価       | 正解か不正解か、コマンド数 | 後輩の信頼度ゲージ、表情の変化、上司の評価                 |
| 再現度     | コミットのノードのみ       | 作業ツリー、ステージ、ローカル、リモート、ファイル内容まで |

## 4. 仕様決めで決めること

1. **gitエンジン**：自作シミュレータ（LGB型。演出に合わせて自由に作れるが工数大）／isomorphic-git＋メモリ上のFS（本物と同じ挙動。ブラウザだけで動く）／WASM版のgit
2. **入力方式**：CLIで打つ／ボタンやカード／両方（序盤はボタン、後半はCLI）
3. **対象者**：完全な初心者／新人エンジニア／研修担当（法人向け）
4. **扱うコマンドの範囲**：init, add, commit, status, log, diff, branch, switch/checkout, merge, rebase, stash, reset, revert, restore, reflog, cherry-pick, tag, clone, fetch, pull, push（force含む）
5. **やらかしシナリオの一覧**と、それぞれの怒られ方と復旧方法
6. **演出の線引き**：上司の怒り方をどこまで強くするか（笑えるがパワハラ描写に見えない程度）
7. **ビジュアル**：ドット絵／立ち絵ノベル風／チャット風UI
8. **ボリュームと構成**：章立て、1章あたりの時間、進捗の保存
9. **技術スタックとホスティング**：React＋Vite、静的ホスティングなど
